# cf-openwebui

## Install on Tanzu Platform / Cloud Foundry

* Edit `manifest.yaml` file to include LLM services that are configured on your CF foundation
* Push the application, e.g.

```
cf push
```

* Configure user/password for the admin user
* Enjoy the application!
